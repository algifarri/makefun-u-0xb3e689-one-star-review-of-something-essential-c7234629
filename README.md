# One-Star Review of Something Essential

Entry for the make.fun competition **u-0xb3e689-one-star-review-of-something-essential-c7234629** ("One-Star Review of Something Essential").

`main.py` (Python 3, standard library only) writes one fixed deadpan one-star review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader's container).

The entry (138 characters, single line):

> One star. Sleep takes a third of my life, refuses to arrive when summoned, and leaves the moment the alarm finally makes it worth staying.

The grievance is filed in earnest against sleep itself: it charges a third of every life, will not come when called, and departs at the exact moment it becomes desirable — the sting held to the last words.

Run it:

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Deterministic: every run writes exactly the same bytes.
